# 600-episode L and XL comparison

Both learned methods trained from scratch on five matched model seeds. The runner validated every 50 episodes and used FAR success first, then mean validation quality, to select the earlier checkpoint in a tie. Test scores include every FAR failure. The test plots were used previously in the 60-episode pilot.
